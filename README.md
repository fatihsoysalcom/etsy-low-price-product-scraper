# Etsy Low Price Product Scraper

This Python script demonstrates how to scrape Etsy search results to find products sorted by price. It specifically targets items with prices very close to a user-defined low value, such as $0.065, by parsing product titles, prices, and URLs from the HTML. The example illustrates basic web scraping techniques using `requests` and `BeautifulSoup`.

## Language

`python`

## How to Run

1. Install dependencies: `pip install requests beautifulsoup4`
2. Run the script: `python main.py`
